# 🎓 AI-ML-PROJECTS-1 | Student Marks Predictor

This is my first AI/ML project that predicts student marks based on study hours using Linear Regression.

### 🚀 Tech Stack
- Python
- Pandas
- Scikit-Learn

### 🧠 How It Works
The model is trained on Hours vs Marks data and can predict future results.

### ▶️ How to Run
pip install -r requirements.txt
python main.py
